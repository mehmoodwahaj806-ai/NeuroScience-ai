About the Model

Architecture: Two independent EfficientNet-B0 convolutional networks, run in sequence.

Stage 1 — Tumor Screening (binary): Outputs a calibrated probability that the slice contains a tumor. The decision threshold was deliberately tuned low (favoring sensitivity over specificity) so that true tumors are very unlikely to be missed, at the cost of more false positives — an appropriate trade-off for a screening tool.

Stage 2 — Subtype Classification (3-class): Only runs if Stage 1 flags a tumor. Classifies the finding as glioma, meningioma, or pituitary tumor.

Out-of-distribution (OOD) detection: Both stages compute an energy score from the network's logits. If an uploaded image doesn't statistically resemble the brain MRI slices the model was trained on (e.g. a non-MRI photo, a heavily corrupted scan), it is flagged as uncertain rather than forced into a confident-sounding but meaningless prediction.

Calibration: Both stages apply temperature scaling to their logits before producing probabilities, so the confidence values reported are calibrated estimates rather than raw softmax output.
